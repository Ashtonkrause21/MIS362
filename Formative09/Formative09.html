Learning Objectives

In this assignment, you will use the same SmartBean sales data used later in Summative09 to practice a complete introductory BI and analytics workflow.

After completing this assignment, you will be able to:

  1. Recognize data-quality problems that can distort analysis.
  2. Use XLOOKUP and VLOOKUP to combine transaction and master data.
  3. Select and use an appropriate Excel analysis method.
  4. Interpret and verify an important business pattern.
  5. Make a supported recommendation while identifying an important limitation.

Assignment Overview

Business intelligence and analytics turn transaction data into useful summaries, patterns, visualizations, and decisions. The process begins with a clear management question and trustworthy data—not with a chart.

Download and open Formative09_SmartBean_BI_Analytics.xlsx. Save a working copy as Formative09.xlsx.

The workbook contains the same 1,200 records from SmartBean_SalesData.csv used in Summative09. Using the same data lets you practice the tools now and apply them more independently later.

Detailed work belongs in the workbook. The three webpage answers should remain brief and communicate the conclusions that resulted from the analysis.

Introduction — Data Quality and Management Questions
  1. Open 0-StartHere and 1-RawSales.
  2. Review the record count, duplicate Transaction IDs, missing CustomerType values, and StoreLocation spacing issues.
  3. Use the helper columns and table filters to inspect at least one example of each issue.
  4. Review the sample management questions and enter one useful practice question in the workbook.
  5. Remember that incorrect or inconsistent data can produce a convincing but misleading summary or chart.

The lookup, analysis, and recommendation exercises depend on trustworthy data and a clear question.

Exercise 1 — Lookup and Data Enrichment
  1. Open 2-LookupPractice.
  2. Review the example XLOOKUP and VLOOKUP formulas in the first transaction row.
  3. Fill the formulas down through the remaining practice transactions.
  4. Verify that ProductCategory and StoreLocation match the master tables.
  5. Compare the modern XLOOKUP structure with the VLOOKUP structure commonly found in older workbooks.
